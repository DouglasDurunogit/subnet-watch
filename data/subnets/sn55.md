## README excerpt (evidence for the brief)

```markdown
# NIOME — rare-disease structural-variant calling subnet

A Bittensor subnet where miners compete to **fine-tune DeepVariant** for short-read
structural-variant (SV) calling. Models are scored on hidden, freshly generated genomes enriched for
rare-disease loci.

- **Format:** king of the hill in periodic **2–3 day epochs** (14,400 blocks = 2 days by default).
  Every validator scores every entrant, plus stock DeepVariant and the defending king, on the same
  hidden task. A challenger takes the crown only if it beats the king by a 0.05 composite margin
  that holds under a paired window bootstrap. Weights are winner-take-all by default.
- **Submission:** a `.dvw` bundle, which is the full weight set (378 tensors) of DeepVariant
  1.10.0's WGS InceptionV3, fine-tuned. No code, no graph. Validators rebuild the network from the
  pinned DeepVariant image and assign the tensors.
- **Genesis king:** stock DeepVariant, owned by the subnet owner (its share is burned).
- **Privacy:** the weights are sealed to the validators' X25519 keys. The public sees *who*
  submitted (hotkey, commit block, model hash) before scoring and the leaderboard after it. **Only
  the king's weights are ever published.**
- **Tasks:** generated locally by every validator from a post-close block hash, so honest
  validators build byte-identical tasks.
- **Validator keys:** each validator serves `<public>/validator_key.json`. Miners seal to the keys
  they fetch with `niome-miner seal --key-source URL` (or `NIOME_KEY_SOURCES`).

  finetune_dv.py      reference miner: training examples -> frozen-backbone fine-tune -> model.dvw

```bash

python3 scripts/deepvariant/pull_image.py /opt/dv-root 1.10.0     # ~2.1 GB, needed for real runs
python3 -m pytest -q
export NIOME_DV_ROOT=/opt/dv-root
python3 scripts/run_local_epoch.py --fresh                        # ~7 min, prints LOCAL_EPOCH_OK
